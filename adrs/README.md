## ✍️ Creating an ADR

When an architectural change or decision is required:

1. Copy the standard ADR format: `Number - Title`, `Status`, `Context`, `Decision`, `Consequences`.
2. Obtain technical steward & security review.
3. Commit to `adrs/` folder.
