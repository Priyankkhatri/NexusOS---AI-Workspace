# NexusOS Applications (`apps/`)

This directory houses frontend applications and user interface client apps.

---

## 🎯 Logical Applications (Planned for Phase 1+)

- `web-dashboard/`: Next.js web application for remote monitoring, session management, approval flows, and audit history.
- `desktop-agent/`: Electron desktop application for local Windows agent execution, tray status, and local authorization notifications.
- `mobile-companion/`: Mobile companion app for quick approvals and alert telemetry.
- `cli/`: Command-line tool for local administrative tasks and development.
